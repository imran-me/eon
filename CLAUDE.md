## What EON is

**One Brain, Multi Decision Layer for the Epal ERP** (`erp.epal.com.bd`, Laravel 12 / MySQL, 12 companies).
Target: presented at **AI Business Summit 2026**, China–Bangladesh Friendship Conference Center, Dhaka (tech leaders, ministries, the PM). EON serves the boss: ask by voice or text → grounded answers with numbers, the rule applied, and the recommended action, across accounts (chart of accounts, GL, journals, ledgers), payroll, HR, expenses, CRM, tasks, employee monitoring/evaluation; a ranked morning brief; an approvals queue; drafts (reminders, warnings, notices).

## Stack — polyglot on purpose (owner's decision, 2026-08-18)

| Layer | Language | Where |
| --- | --- | --- |
| API, ERP DB access, memory, auth, cron, LLM agent | PHP 8.2 (plain, Laravel-compatible; later a Laravel `eon` module inside the ERP) | `server/` on Hostinger, next to the ERP |
| Heavy analytics/ML: forecasting, anomaly detection, evaluation model, Bangla/English NLP, Excel/PDF reports | Python (`server/py/`, called by PHP/cron, JSON in/out) | Hostinger SSH python3 or a VPS |
| Set-based computation (aging, TB, rollups) | SQL / MySQL | ERP database (read-only user) |
| Face: companion, voice capture/speech, screens, offline fallback | JavaScript | `ai-companion/`, `app/` |

Language model: Claude `claude-opus-5` via the official PHP SDK (`anthropic-ai/sdk`), tool use over the ERP data, adaptive thinking (default), effort `high`. Offline rule brain = fallback only.
