EON — SIDE PANEL (stall wing)
Bangladesh AI Business Summit 2026 · Stall U-13 · Milky Way Hall, BCFCC

SIZE
  Trim (finished panel)   2 ft x 8.3 ft   =  24 x 99.6 in
  File size (with bleed)  26 x 101.61 in
  Bleed                   1 in on every side  -> trim 1 in off each edge
  Background runs to the bleed edge, so a few mm of drift costs nothing.

FILES
  EON-side-panel-2x8.3ft.pdf            vector. USE THIS IF THE PRINTER
                                        ACCEPTS PDF - type stays sharp at
                                        any size.
  ...-300dpi.png / .tif    7800 x 30483 px   300 dpi at final size
  ...-150dpi.png / .tif    3900 x 15242 px   150 dpi at final size

  The TIFFs are LZW (lossless) and carry the dpi tag, so Photoshop opens
  them at true physical size instead of guessing 72 dpi. Both PNG and TIFF
  hold the same pixels; TIFF is usually what a press wants.

WHICH ONE
  PDF for anything that takes it.
  300 dpi only if the printer insists - at 2 x 8.3 ft it is far more than
  needed and the files are heavy.
  150 dpi at final size is the normal standard for large format and is
  what most shops will ask for.

COLOUR
  RGB, untagged. Convert to the press's own CMYK profile at their end -
  a blind RGB->CMYK here would dull the blues. The deep navy (#0B1222)
  and the blue (#2F62D9) both hold up in CMYK; the teal (#0E86A6) will
  read slightly duller on press, which is expected.

FONTS
  Already outlined in the raster files. In the PDF the text is live, so if
  the shop edits it, have them outline first - the Bangla will drop to
  boxes on a machine with no Bengali font.

DO NOT PRINT the TV-guide file from the parent folder; that one has a red
overlay and is only for checking the television position on the back wall.
