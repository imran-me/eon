Opening Balance Entry — Design Idea

How to add: Customer Receivables · Supplier Payables · Existing Assets  |  For your ERP Journal Module

Concept: All three flows work the same way — they create a Journal Entry using an "Opening Balance Equity" account as the counter-entry. This keeps your double-entry books balanced when you enter historical/existing financial data into a fresh accounting system. Each type gets its own dedicated modal button (similar to your existing Credit/Debit Journal buttons).

Add Customer Due Payments (Receivables)

Use this when a customer already owes you money — from a previous invoice or credit sale done outside the system. The system will record it as money owed to you (Accounts Receivable) balanced against the Opening Balance Equity account.

How to Implement in Your Laravel ERP

1

Add "Opening Balance Equity" Account — Add one special chart-of-accounts entry (e.g. code 3000, type equity, name Opening Balance Equity). This is the counter-account for all three journal types. All three features debit/credit against this single account.

2

Add "Accounts Receivable" & "Accounts Payable" Chart of Accounts — You may need sub-accounts per customer/supplier (code 1100 for AR, 2100 for AP) or one shared account if you just track totals. The customer/supplier name goes in the journal item note field.

3

Add 3 New Buttons to Journal Index Header — Just like your existing Add Credit Journal and Add Debit Journal buttons, add: "Opening Receivable", "Opening Payable", "Opening Asset". Each opens its own modal.

4

Multi-row Modal Form — Unlike the current single-amount modals, these need a dynamic row table (add/remove rows via JS). Each row collects customer/supplier/asset + amount. On submit, generate journal items: one DR per row + one CR total to the Opening Balance Equity account.

5

Reuse Existing journals.store Route — No new controller needed. The payload format is the same as your current credit/debit journal. Set source = 'opening_balance' so the journal list shows it with a distinct badge color. Add 'opening_balance' to your sources filter list.

6

Receivable Tracking (Optional Enhancement) — Store customer_id on journal_items table (add a nullable customer_id column via migration). This lets you later build an Aging Report — grouping overdue balances per customer. Same pattern for supplier_id on payable items.
