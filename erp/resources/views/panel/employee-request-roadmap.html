📥 Require
Company / Manager initiates — requires something from employee.
Documents, actions, submissions, compliance tasks.
🏢 Initiated by Company / Manager

Advance Salary
Request Exists
  • Employee submits amount & reason
  • Manager approval workflow
  • Auto-deduct from next payslip
  • Installment recovery option
  • Balance tracker per employee

Loan Request
Request Exists
  • Loan amount, tenure, purpose
  • Interest rate config (0% internal)
  • EMI schedule auto-generation
  • Monthly deduction from salary
  • Outstanding balance report
loans EMI interest

Project Payment Request
Request New
  • Link request to specific project
  • Expense type: travel, procurement, misc
  • Bill/receipt upload attachment
  • Finance team approval + disbursement
  • Project cost tracking integration
projects expense attachment

Salary Dispute / Issue
Request New
  • Report wrong deduction / missing amount
  • HR marks issue as under review
  • Correction entry on next payslip
  • Dispute history log per employee
  • Resolution comment + timestamp
payslip dispute HR

Equipment / Resource Request

  • Request laptop, tools, supplies
  • Quantity & urgency level
  • Procurement team routing
  • Asset assigned to employee
  • Return tracking on exit
assets procurement

Travel & Allowance Request
Request New
  • Trip purpose, destination, dates
  • Pre-approved travel budget
  • Per-diem auto-calculation
  • Post-trip bill submission
  • Reimbursement to next salary
travel allowance reimbursement

Bonus / Incentive Request
Request Extend
  • Manager nominates employee
  • Performance basis or festival bonus
  • Finance approval + payslip merge
  • Tax consideration flag

Emergency Fund Request
Request New
  • Medical / family emergency category
  • Fast-track approval (≤24h)
  • One-time grant or deductible
  • CEO/MD final authority
  • Separate fund limit per year

REQUIRE 📥 Company → Employee Company requires action from employee
📋
Document Submission
Require New
  • HR requires NID, TIN, certificates
  • Deadline with reminder notification
  • Employee uploads via portal
  • HR verifies & marks fulfilled
  • Missing doc alert on payslip
compliance NID upload
🎓
Training / Course Completion
Require New
  • Manager assigns mandatory training
  • Deadline + escalation if missed
  • Employee submits certificate/proof
  • Completion status in profile
  • Linked to appraisal score
training appraisal mandatory
🔄
Asset Return Requirement
Require New
  • Triggered on resignation / exit
  • Checklist: laptop, ID card, keys
  • Each item marked returned by HR
  • Final settlement blocked until clear
  • Condition report at return
exit assets settlement
📜
Policy Acknowledgment
Require New
  • HR publishes new policy document
  • All employees required to sign
  • Digital signature / checkbox confirm
  • Timestamp of acknowledgment stored
  • Overdue list visible to HR/admin
policy signature compliance
📊
Performance Self-Review
Require New
  • HR opens review cycle with deadline
  • Employee fills self-assessment form
  • Manager adds rating + comments
  • Both parties sign off on review
  • Data feeds into appraisal module
appraisal self-review KPI
⏱️
Timesheet / Work Log
Require New
  • Weekly/monthly timesheet required
  • Project-wise hours breakdown
  • Manager reviews & approves
  • Late submission auto-flagged
  • Linked to billing/project cost
timesheet projects billing
🏢
Office Requisition
Require New
  • Office needs item/service (stationery, furniture, maintenance)
  • Department head raises requisition
  • Category: supplies / equipment / repair / service
  • Estimated cost + vendor suggestion
  • Admin/Finance approves & assigns procurement
  • Delivery confirmed → requisition closed
office supplies maintenance procurement
🛋️
Interior Project Requirement
Require New
  • Linked to specific interior project
  • Material / item requirement with specs
  • Quantity, unit, estimated cost
  • Site manager raises — admin approves
  • Vendor quotation upload support
  • Delivery schedule + milestone tracking
  • Cost mapped to project budget
interior materials project-cost milestone
