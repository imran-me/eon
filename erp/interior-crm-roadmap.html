🔀 Lead → Project Conversion Process
💡
কীভাবে Convert করবেন: Lead status Won হওয়ার পর একটি "Convert to Project" button থাকবে। এই button click করলে automatically Project তৈরি হবে এবং Lead এর data গুলো Project এ copy হবে।
🔧 LeadManagerController.php — convertToProject() method
public function convertToProject($leadId) { $lead = Lead::findOrFail($leadId); // Project তৈরি করুন $project = Project::create([ 'project_name' => 'Interior - ' . $lead->name, 'customer_id' => $lead->customer_id, 'project_category_id' => /* Interior category */, 'budget' => $lead->interior->budget_max, 'description' => $lead->notes, 'company_id' => auth()->user()->company_id, 'status' => 'in_progress', 'start_date' => now(), ]); // Lead এ project_id save করুন $lead->update([ 'project_id' => $project->id, 'converted_at' => now(), ]); return redirect()->route('projects.show', $project->id); }
