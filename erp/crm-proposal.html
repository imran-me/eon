01 — Executive Summary
Why We Need a Unified CRM

EPAL ERP currently handles Air Ticket sales, Visa processing, and Software project management as separate modules with no unified lead pipeline, follow-up tracking, or sales funnel visibility. This proposal outlines the development of a Unified CRM module that brings all customer-facing activities under one intelligent dashboard — increasing team efficiency, reducing missed follow-ups, and improving conversion rates across all service lines.

Core Objective: Build a single, powerful CRM system within EPAL ERP where every lead — whether for an air ticket, visa application, or software project — follows a structured pipeline from first contact to confirmed sale, with automated follow-up alerts, performance analytics, and team assignment management.
⚠️

Current Problems

  • Lead tracking manually done (calls/WhatsApp/notes)
  • No unified follow-up alert system
  • Air ticket, visa & software leads tracked separately
  • No conversion rate or sales funnel visibility
  • Missed leads due to no reminder system
  • No agent performance tracking
✅

Proposed Solution

  • Unified CRM dashboard with Today's Summary
  • Automated follow-up alerts (Overdue/Today/Tomorrow)
  • Lead type system: Air Ticket, Visa, Software
  • Visual pipeline: Kanban & Funnel view
  • Smart reminders via Email, SMS & WhatsApp
  • Agent-wise performance reports

07 — Technical Plan
Required Database Changes

All new tables extend the existing database structure without breaking current functionality. Existing models (Lead, LeadFollowup, VisaProcess, etc.) will be enhanced, not replaced.

-- 1. Enhance existing leads table ALTER TABLE leads ADD lead_type ENUM('air_ticket','visa','software','other') ADD service_category VARCHAR(100) -- 2. Air Ticket specific details CREATE TABLE lead_air_tickets ( lead_id FK → leads.id route_from VARCHAR(10) -- e.g. DAC route_to VARCHAR(10) -- e.g. DXB travel_date DATE pax_count INT ticket_class ENUM('economy','business','first') preferred_airlineVARCHAR(100) ) -- 3. Visa specific details CREATE TABLE lead_visas ( lead_id FK → leads.id destination_country FK → countries.id visa_type ENUM('tourist','business','student','work') travel_date DATE document_status ENUM('pending','complete','submitted') payment_status ENUM('pending','partial','paid') ) -- 4. Lead quote tracking CREATE TABLE lead_quotes ( lead_id FK → leads.id estimate_id FK → estimates.id status ENUM('sent','viewed','accepted','rejected') payment_status ENUM('pending','partial','paid') )
