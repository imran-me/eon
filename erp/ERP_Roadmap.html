(Credit & Debit)		 Working Double-entry accounting সহ JournalEntry + JournalItem model আছে। Debit/Credit column আছে। Party-wise tracking (party_type, party_id) আছে। Voucher print আছে। Web + API দুটোই আছে। Opening balance entry কোনো dedicated UI নেই — Journal দিয়ে manually করতে হয়। Party-wise ledger report (কোন party-র কত debit/credit) নেই। Journal থেকে auto payment schedule link নেই।
📅 Payment Schedule
(Regular)		 Partial PaymentSchedule model আছে। Approval workflow আছে। Reschedule আছে। Pay/Receive type আছে। Ad-hoc route আছে। Log/audit trail আছে। Company-wise filter আছে। Partial Payment নেই! — একটি schedule-এ paid_amount, due_amount, remaining_amount নেই। একটি schedule পুরো paid বা unpaid। Installment-wise payment track করা যায় না।

🔑 সমাধান: PaymentSchedule-এ Partial Payment যোগ করার উপায়

payment_schedules table-এ নিচের fields যোগ করতে হবে:
paid_amount (decimal, default 0) | remaining_amount (decimal) | partial_payments (JSON log) | payment_mode (bank/cash/mobile)

তাহলে একটি schedule-এ multiple partial payments করা যাবে এবং remaining automatically calculate হবে। এই একটা change-এ Sales Schedule, Purchase Schedule, এবং Ad-hoc Schedule তিনটাই সমাধান হবে।

👤 Customer & Supplier Profile Page — সম্পূর্ণ Implementation Plan

📌 সমস্যা

Customer model-এ Sales, TicketSales, Visa-র সাথে কোনো relationship নেই। Supplier model-এ Purchases-এর সাথে relationship নেই। কোনো profile page নেই। একজন customer-এর profile-এ গিয়ে তার সব transaction, dues, invoices দেখা যায় না।

🔗 Model-এ যা যোগ করতে হবে

// app/Models/Customer.php — এই relationships যোগ করুন public function sales() { return $this->hasMany(Sale::class); } public function visaProcesses() { return $this->hasMany(VisaProcess::class); } public function paymentSchedules() { return $this->morphMany(PaymentSchedule::class, 'party'); } public function totalReceivable(): float { return $this->sales()->sum('due_amount'); } // app/Models/Supplier.php — এই relationships যোগ করুন public function purchases() { return $this->hasMany(Purchase::class); } public function paymentSchedules() { return $this->morphMany(PaymentSchedule::class, 'party'); } public function totalPayable(): float { return $this->purchases()->sum('due_amount'); }
