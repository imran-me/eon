Implementation Steps

Step-by-step কাজের ধারা

Step 1 — Route যোগ করো

web.php-এ company dashboard route add করো।

GET /company/{company}/dashboard name: company.dashboard

Step 2 — CompanyDashboardController তৈরি করো

Company ID নিয়ে সব related data (sale, purchase, expense, bank, employee, ticket, visa) query করবে।

Step 3 — Sidebar update করো

layout/app.blade.php-এ companies loop করে nav items বানাও। Alpine.js দিয়ে collapse/expand।

Company::where('status', 1)->get() route('company.dashboard', $company->id)

Step 4 — Dashboard view তৈরি করো

resources/views/company/dashboard.blade.php — stat cards, charts (Chart.js), recent transactions table।

resources/views/company/dashboard.blade.php

Step 5 — Active company highlight

Sidebar-এ current company-র link active style করো। Session বা route parameter দিয়ে detect করো।

request()->route('company') == $c->id

Existing Model — Company.php

যা আছে এবং যা যোগ করতে হবে

// app/Models/Company.php — বিদ্যমান relations
class Company extends Model {
  $fillable = ['name', 'address', 'email', 'phone', 'logo', 'status'];

  // ✅ আছে
  public function users() → hasMany(User)

  // 🆕 যোগ করতে হবে (যদি company_id FK থাকে)
  public function sales() → hasMany(Sale)
  public function purchases() → hasMany(Purchase)
  public function expenses() → hasMany(Expense)
  public function employees() → hasMany(Employee)
  public function banks() → hasMany(Bank)
}

Build Order (Priority)

এই order-এ কাজ করলে সবচেয়ে দ্রুত হবে

🖨️ Print/export company report
